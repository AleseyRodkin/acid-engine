AcidEngine — контрактно-ориентированная операционная система разработки.  
Все элементы системы описываются единым механизмом — **контрактом**.  
Проект имеет строгую иерархию уровней, где каждый следующий уровень реализуется средствами предыдущего.

## Уровни

### Level 0 — Представления кода
- **LiveCodeView** — живой исполняемый код (обычные функции Python или любого другого языка).
- **AIReferenceView** — ссылочное представление для ИИ (каждый атом — отдельный `ScriptModule`, ИИ правит только атом).
- **HumanReadableView** — человекочитаемое отображение контрактов (Спецификация / Вход / Выход / Реализация) и графа зависимостей.

### Level 1 — Хранилище данных
- **DataPlane** — абстрактный интерфейс хранилища (`store`, `load`, `exists`).
- Временная реализация: `InMemoryDataPlane`. В будущем планируется реализация на Rust.

### Level 2 — Контрактный слой
- **Contract** — базовый класс контракта (сущность, характеристики, правила, действия).
- **Specification**, **Policy**, **Parameters**, **ImplementationRequirements**.
- **ConstraintResolver** со стратегиями (min/max, intersection/union, boolean strengthen, string enum).
- **Семантические предикаты** (equals, contains, matches, cardinality, json_schema, jsonpath, invariant, security).
- **InterfaceContract** — контракт всего приложения.

### Level 3 — Замкнутый контур
- **Pipeline** — явный класс, инкапсулирующий цепочку Container → Script → Module → Graph → Interface → main().
- **ScriptModule**, **AsyncScriptModule**, **ContainerSnapshot**, **PortRef**, **DependencyGraph**.
- **ExecutionProfile** — универсальные интерфейсы упаковки проекта в артефакты:
  - `LibraryProfile`
  - `CLIProfile`
  - `DesktopProfile`
  - `ServiceProfile`
  - `SaaSProfile`
  - `EmbeddedProfile`

### Level 4 — Библиотека атомов
- **ContractRegistry** — реестр всех контрактов с историей версий, разрешением ссылок и поиском по хешу.

## Сервисы (развиваются параллельно)
- **Логирование** (`ExecutionLogger`)
- **AI-контекст** (`AIContextProvider`) — построение контекста для LLM.
- **DSL** — парсер человекочитаемого языка контрактов.
- **Безопасность** — предикат `security` для запуска внешних сканеров уязвимостей.

## Принцип самоприменимости
AcidEngine сам является проектом, собирает сам себя через собственные контракты и профили, а затем упаковывает полученную библиотеку в CLI, Desktop и другие формы. Любой новый механизм обязан работать как для пользовательских проектов, так и для самой платформы.

## Матрёшка заглушек
Каждый уровень получает ссылку на нижележащий и по умолчанию делегирует вызовы ему. При добавлении новой функциональности переопределяется только нужный метод, остальное подхватывается автоматически.
